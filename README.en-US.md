# Sona Personal Match-History Edition

Based on **Sona v1.10.0 by the original author WJZ-P**, this Pengu Loader edition retains the **AGPL-3.0** license. It adds richer player profiles and match reports, player search with friends and recent visits, champion-select and in-game team overviews, Korean OP.GG matchups, rank details, replay controls, display settings, and shared themes. Team-card layouts take inspiration from League Akari. [Original project](https://github.com/WJZ-P/sona)

The customized release was prepared on 2026-11-07. See the [personal edition installation guide](README_个人版.md) and [changelog](CHANGELOG.md).

## Installation

Download the installation ZIP from [this repository's Releases](https://github.com/chii-primenumber/sona-personal/releases), extract the sona folder into the Pengu Loader plugins directory, and restart the League client. Back up the existing plugin and custom assets before replacing them. Press **F1** to open Sona.
