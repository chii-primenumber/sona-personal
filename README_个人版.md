# Sona 个人战绩增强版

版本为 `1.10.0-personal.4`，基于 WJZ-P 的 Sona v1.10.0，沿用原项目的 AGPL-3.0 许可。队伍卡片参考 Akari 的布局。[上游项目](https://github.com/WJZ-P/sona/tree/v1.10.0)

## 安装与回退

1. 退出英雄联盟客户端。在 **Pengu Loader → Plugins** 中打开插件目录。
2. 将已经安装的 `sona` 文件夹整个备份到**插件目录外**。先留好这一份，以便回退。
3. 解压安装包，将解压得到的 `sona` 文件夹放到插件目录。确认结构为 `plugins/sona/index.js`，旁边有 `index.css` 和 `assets`。
4. 如果原版 `assets` 中有你自己的壁纸、视频或头像，把这些自定义文件复制到新版 `sona/assets` 中。请只启用一份 Sona。保留 `sona` 文件夹名，以便沿用原先的资源路径和设置。
5. 刷新 Pengu Loader 的插件列表，确认 Sona 已启用，再启动 LOL 客户端。个人版在客户端中显示版本 `1.10.0-personal.4`。

回退时，退出客户端，把个人版移出插件目录，再把备份的原版 `sona` 移回去，刷新插件列表后重启。定制版不会在启动时主动弹出上游更新提示，避免将定制代码误覆盖。

## 战绩入口

| 场景 | 从哪里打开 | 可以看什么 |
|---|---|---|
| 个人战绩 | **F1 → 工具 → 查询战绩**，输入 `名字#Tag`；或在开启 **英雄选择阶段增强** 后点击 BP 队友头像 | 当前段位、等级、有效样本、KDA、参团、伤害与经济占比、英雄点数、常玩英雄、近期队友及对手；每局可展开参赛者详细战报 |
| 生涯 | 点击生涯页右侧的 **详细战绩**。自己的生涯页入口位于原搜索框下方 | 打开前台生涯页对应的召唤师战绩 |
| 历史战报和结算页 | 右键计分板里的召唤师，再选择 **详细战绩** | 打开该召唤师的个人战绩 |
| BP 己方五人 | 选人界面点击 **己方五人战绩**。入口可在工具页的 **五人 / 十人战绩总览** 中开关 | 横排玩家卡显示段位、KDA、胜率、常玩英雄和近期对局 |
| 开局后双方十人 | 进入游戏后切回客户端，点击 **十人战绩总览** 或 **对局分析**。原有的 **全局战力分析弹窗** 可在进游戏后自动打开 | 蓝红双方各一组横排玩家卡，窄窗口下自动换行 |

详细战绩页可输入 `名字#编号` 搜索玩家，再用「返回」切回上一位。点玩家卡片的头像或名字可打开个人战绩，点卡片里的近期对局可打开单场战报。个人战绩默认每批 50 场，可改为 20 或 100 场。队伍总览支持按模式筛选。

## 数据口径

- 近期统计、常玩英雄、队友与对手都来自当前已加载的样本；胜率排除重开、终止及未知胜负的对局。页面会显示有效场次。英雄点数来自独立的熟练度接口。
- 段位卡片显示查询时的段位，不是历史那一局的段位。详细战报只展示接口实际返回的字段。部分大区可能没有英雄点数、海克斯名称或辅助数据，页面会显示不可用或留空。
- 使用客户端备用战绩接口时，按模式筛选只在最近 100 场中检索，页面会说明这个范围。新增页面不需要 ChatGPT API Key。

## 验证与源码

生涯和计分板入口依据本机 16.22 客户端的界面结构实现。浏览器模拟覆盖了两个队伍页、近期对局、召唤师头像、生涯按钮和两处右键菜单。三个新增客户端入口还需安装后实测。

源码包包含完整的定制源码。安装依赖后运行 `npm run build`，构建结果保存在 `dist`。个人修改记录在本地 Git 分支 `personal/match-history`。
