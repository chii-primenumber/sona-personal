# Sona 个人战绩增强版

版本为 `1.10.0-personal.11`，基于 **原作者 WJZ-P** 的 **Sona v1.10.0** 定制，沿用原项目的 **AGPL-3.0** 许可。主要增强个人战绩、玩家搜索、队伍总览、对位与回放，并提供全局主题和显示设置。队伍卡片参考 League Akari 的布局。[上游项目](https://github.com/WJZ-P/sona/tree/v1.10.0)

## 安装与回退

1. 退出英雄联盟客户端。在 **Pengu Loader → Plugins** 中打开插件目录。
2. 将已经安装的 `sona` 文件夹整个备份到**插件目录外**。先留好这一份，以便回退。
3. 将交付目录里的 `sona` 文件夹复制到插件目录。确认结构为 `plugins/sona/index.js`，旁边有 `index.css` 和 `assets`。
4. 如果原版 `assets` 中有你自己的壁纸、视频或头像，把这些自定义文件复制到新版 `sona/assets` 中。请只启用一份 Sona。保留 `sona` 文件夹名，以便沿用原先的资源路径和设置。
5. 刷新 Pengu Loader 的插件列表，确认 Sona 已启用，再启动 LOL 客户端。个人版在客户端中显示版本 `1.10.0-personal.11`。

回退时，退出客户端，把个人版移出插件目录，再把备份的原版 `sona` 移回去，刷新插件列表后重启。定制版不会在启动时主动弹出上游更新提示，避免将定制代码误覆盖。

## 战绩入口

| 场景 | 从哪里打开 | 可以看什么 |
|---|---|---|
| 个人战绩 | **F1 → 工具 → 查询战绩**，输入 `名字#Tag`；或在开启 **英雄选择阶段增强** 后点击 BP 队友头像 | 当前段位、等级、有效样本、KDA、参团、伤害与经济占比、英雄点数、常玩英雄、近期队友及对手；每局可展开参赛者详细战报 |
| 生涯 | 点击生涯页右侧的 **详细战绩**。自己的生涯页入口位于原搜索框下方 | 打开前台生涯页对应的召唤师战绩 |
| 历史战报和结算页 | 右键计分板里的召唤师，再选择 **详细战绩** | 打开该召唤师的个人战绩 |
| BP 己方五人 | 选人界面点击 **对局信息**。入口可在工具页的 **五人 / 十人战绩总览** 中开关 | 横排玩家卡显示段位、KDA、胜率、常玩英雄和近期对局 |
| BP 敌方英雄对位 | 排位或自定义征召选人时左键点击右侧已锁定的英雄头像 | 选择该英雄的分路和段位，查看韩服单双排的对位胜率及样本场次 |
| 开局后双方十人 | 进入游戏后切回客户端，点击 **十人战绩总览** 或 **对局分析**。原有的 **全局战力分析弹窗** 可在进游戏后自动打开 | 蓝红双方各一组横排玩家卡，窄窗口下自动换行 |

在详细战绩页点击「搜索玩家」，可按名字、完整的 `名字#编号` 或 PUUID 查询。左侧是可分别筛选的好友和最近访问，点击玩家打开战绩，用「返回」切回上一位。国服可选择互通大区，并通过「合区参照」查看原区服归属。最近访问在本机保留 20 位。

点队伍卡片的头像或名字可打开个人战绩，点卡片里的近期对局可打开单场战报。个人战绩默认每批 50 场，可改为 20 或 100 场。队伍总览支持按模式筛选。

点击「近期常玩英雄」的头像可筛选该英雄，再点一次同一头像可回到全部英雄。「最高输出」表示该玩家在这场对局中对英雄造成的伤害位列本队第一。

队伍卡片分两行显示单双排和灵活组排，段位用客户端徽章表示，胜点显示在徽章旁边。

个人战绩右上角显示当前段位徽章和各队列的赛季最高段位。单场战报的伤害、承伤与经济条以本场同项最高值为满格，旁边的百分比是队内占比。伤害条分色显示物理、魔法和真实伤害。

点击个人战绩的段位卡可查看该队列的历史段位，包含客户端提供的上赛季最高和结算。名字旁的复制按钮复制完整的 `名字#编号`。对局卡片右侧的阵容默认只显示名字，悬停可看完整 ID。选人阶段会为同一开黑队伍的名字着色，组队依据排队前的房间成员。

对局卡片的「下载回放」在客户端确认下载完成后会变为「播放回放」。可用范围取决于登录大区、客户端版本和回放状态。

鼠标悬停在装备或海克斯图标上可查看深色说明。点击右上角的「显示设置」，可分别勾选五人／双方总览、个人详细战绩和单场详细战报要显示的项目。勾选会立即生效并保存在本机，每页都可以恢复默认。

在「F1 → 设置 → 插件主题」中可切换「客户端（黑金）」和「深色蓝灰」。主题会同步应用到 Sona 主面板、搜索、战绩、对位和设置弹窗，并记住选择。

「工具 → 社交 → 解锁隐藏生涯」默认开启，切换后重启客户端生效。此项作用于客户端的查看开关，页面仍取决于服务器返回的资料。

## 数据口径

- 近期统计、常玩英雄、队友与对手都来自当前已加载的样本；胜率排除重开、终止及未知胜负的对局。页面会显示有效场次。英雄点数来自独立的熟练度接口。
- 段位卡片显示查询时的段位。赛季最高段位未返回时显示「—」。部分大区的英雄点数、海克斯名称或辅助数据可能缺失。
- 客户端缺少海克斯效果说明时，海克斯大乱斗和斗魂竞技场分别从 ARAM.GG 和 CommunityDragon 读取当前公开资料，旧对局的说明可能与当时版本有差异。
- 使用客户端备用战绩接口时，按模式筛选只在最近 100 场中检索，页面会说明这个范围。新增页面不需要 ChatGPT API Key。

## 验证与源码

浏览器模拟覆盖了主题切换、玩家搜索、跨大区请求路由、显示设置、段位徽章、占比条、装备与海克斯提示，以及两个队伍页、生涯按钮和右键菜单。真实客户端的跨区接口仍待安装后确认。

定制源码和修改记录保存在本地 Git 分支 `personal/match-history`。安装依赖后运行 `npm run build`，构建结果保存在 `dist`。
