# Sona 个人战绩增强版

版本：`1.10.0-personal.1`。基于 [WJZ-P / Sona v1.10.0](https://github.com/WJZ-P/sona/tree/v1.10.0) 的个人定制副本，原项目作者及 AGPL-3.0 许可保留。界面以你提供的 Akari 截图为参照。

## 安装与回退

1. 退出英雄联盟客户端。在 **Pengu Loader → Plugins** 中打开插件目录。
2. 将已经安装的 `sona` 文件夹整个备份到**插件目录外**。先留好这一份，以便回退。
3. 解压安装包，将解压得到的 `sona` 文件夹放到插件目录。确认结构为 `plugins/sona/index.js`，旁边有 `index.css` 和 `assets`。
4. 如果原版 `assets` 中有你自己的壁纸、视频或头像，把这些自定义文件复制到新版 `sona/assets` 中。请只启用一份 Sona。保留 `sona` 文件夹名，以便沿用原先的资源路径和设置。
5. 刷新 Pengu Loader 的插件列表，确认 Sona 已启用，再启动 LOL 客户端。个人版在客户端中显示版本 `1.10.0-personal.1`。

回退时，退出客户端，把个人版移出插件目录，再把备份的原版 `sona` 移回去，刷新插件列表后重启。定制版不会在启动时主动弹出上游更新提示，避免将定制代码误覆盖。

## 三个使用场景

| 场景 | 从哪里打开 | 可以看什么 |
|---|---|---|
| 个人战绩 | **F1 → 工具 → 查询战绩**，输入 `名字#Tag`；或在开启 **英雄选择阶段增强** 后点击 BP 队友头像 | 当前段位、等级、有效样本、KDA、参团、伤害与经济占比、英雄点数、常玩英雄、近期队友及对手；每局可展开参赛者详细战报 |
| BP 己方五人 | 选人界面点击 **己方五人战绩**。按钮默认启用，可在工具页的 **五人 / 十人战绩总览** 中切换 | 同时比较己方队员的当前英雄、段位、近期胜负、KDA、常玩英雄等。点队员卡片进入个人战绩 |
| 开局后双方十人 | 进入游戏后切回客户端，点击 **十人战绩总览** 或 **对局分析**。开启原有的 **全局战力分析弹窗** 可在进游戏后自动打开 | 蓝红双方的近期战绩、位置、段位、常玩英雄；客户端提供预组队信息时会显示。可切换紧凑与详细显示 |

个人战绩默认每批 50 场，可改为 20 或 100 场，再继续加载。队伍总览可在本局模式和全部模式之间切换。单局战报中可切换 **战斗与经济**、**治疗、控制与视野** 两类数据。

## 数据口径

- 近期统计、常玩英雄、队友与对手都来自当前已加载的样本；胜率排除重开、终止及未知胜负的对局。页面会显示有效场次。英雄点数来自独立的熟练度接口。
- 段位卡片显示查询时的段位，不是历史那一局的段位。详细战报只展示接口实际返回的字段。部分大区可能没有英雄点数、海克斯名称或辅助数据，页面会显示不可用或留空。
- 使用客户端备用战绩接口时，按模式筛选只在最近 100 场中检索，页面会说明这个范围。新增页面不需要 ChatGPT API Key。

## 验证与源码

已通过 TypeScript 检查和生产构建，并在浏览器中使用虚构对局验证了手动查询、BP 头像入口、己方五人、游戏后十人、筛选、翻页、接口降级、单局详细战报及两层弹窗关闭。真实 LOL 客户端的接口和各模式表现仍需安装后验证。

源码包包含完整的定制源码。安装依赖后可运行 `npm run build`，构建结果保存在 `dist`，构建不会部署到 Pengu Loader 的插件目录。上游基线：`38b3c0de15d64999b2648f3ad80d385597b206c3`。
