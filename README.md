# Sona 个人战绩增强版

当前源码版本 **1.10.0-personal.27**。基于 **WJZ-P 的 [Sona v1.10.0](https://github.com/WJZ-P/sona/tree/v1.10.0)** 开发，通过 Pengu Loader 加载，沿用 **AGPL-3.0** 许可。

**本个人版新增功能主要参考 Hanxven 及贡献者的开源项目 [League Akari](https://github.com/LeagueAkari/LeagueAkari)**，包括个人战绩、队伍卡片、玩家搜索、数据展示与交互，并适配 Akari 评分机制。Akari 相关评分代码的 MIT 许可随包保留，见 [评分来源与口径](AKARI评分说明.md) 和 [MIT 许可](assets/licenses/LeagueAkari-MIT.txt)。感谢两个上游项目的作者与贡献者。

## 下载与一键安装

本版提供完整 Windows 一键安装包和仅插件包。

- **首次使用**：[下载 Windows 一键安装包](https://github.com/chii-primenumber/sona-personal/releases/download/v1.10.0-personal.27/sona-v1.10.0-personal.27-one-click-windows.zip)，内含官方 Pengu Loader v1.1.6、Sona、一键安装脚本和说明。
- **已有 Pengu Loader**：也可下载 [仅 Sona 插件包](https://github.com/chii-primenumber/sona-personal/releases/download/v1.10.0-personal.27/sona-v1.10.0-personal.27.zip)。
- [本次 Release 与 SHA256 校验文件](https://github.com/chii-primenumber/sona-personal/releases/tag/v1.10.0-personal.27) · [安装说明](installer/INSTALL.md) · [更新记录](CHANGELOG.md)。

完整解压一键安装包，退出英雄联盟客户端和 Loader 管理窗口，双击 **一键安装.cmd**，允许 Windows 管理员授权，等待完成后重新启动客户端，按 **F1** 打开 Sona。

脚本自动寻找客户端、复用或安装 Loader、备份旧插件及配置、保留自定义资源、安装并激活。找到多个客户端时选序号；搜索不到时粘贴游戏或 LeagueClient 目录。缺少 C++ 运行库时会从微软官网下载并校验后安装。适用于 64 位 Windows 10（1803 起）／11。

## 个人版新增功能

### 完整个人战绩

- 同一页面整合近期总览、战绩明细、英雄统计、英雄点数、近期队友和对手。
- 支持按游戏模式、英雄、位置和胜负筛选，隐藏重开／终止，清除筛选及继续分页；每批可加载 20／50／100 场。
- 显示胜负、胜率、KDA、参团率、伤害／承伤／经济占比、补刀、视野、治疗与护盾等数据。
- 常用英雄可点击筛选，再次点击恢复全部；悬停使用表格展示当前评分、KDA、伤转、参团、占比、分均伤害和金币等。
- 名字完整显示，编号分开弱化，提供完整 ID 复制按钮；等级位于头像右下角，使用半透明背景。

### 全局 Akari／Sona 评分切换

- 主菜单底部一键切换评分机制并记住选择；新配置默认 Akari。
- Akari 按 1.5.1 源码适配九项评分，保留原始 **0–17 分**和两位小数；Sona 保留 **3–16 分**和一位小数。
- 个人页、五人／十人卡片、大厅与选人分析同步使用当前机制，已加载记录直接重算，无需重新查询。

### BP 五人及游戏双方十人详情

- 选人界面查看己方五人；开局后在客户端查看蓝红双方十人，点击名字或头像可进入个人战绩。
- 顶部使用紧凑的“对局详情”，模式直接采用当前实际队列，仍可手动选择；刷新和显示设置使用图标。
- 卡片显示胜率、KDA、常用英雄、近期对局与可选表现数据；点常用英雄筛选这张卡片，再点恢复。
- 锁定英雄后用英雄头像替换召唤师头像；单双排与灵活组排的段位图标、胜点并排显示。
- 预组队名字和卡片边框采用相同鲜明颜色，编号保留暗色；胜场使用蓝底、负场使用暗红底。
- 游戏中“对局详情”入口采用与“配装推荐”相同的客户端按钮风格，替换游戏进行中的文字提示；兼容原有自动战力分析入口。

### 十人单场战报

- 展开一场对局即可查看十人英雄、KDA、伤害、承伤、金币、补刀、参团、装备、符文、技能和海克斯。
- 支持“战斗与经济”和“治疗、控制与视野”视图；伤害条区分物理、魔法和真实伤害，百分比显示队内占比。
- 点击符文查看主系、副系、属性符文，以及客户端返回的伤害、护盾、治疗和触发次数。
- 装备、技能、符文、英雄与海克斯统一提供主题化悬浮说明，海克斯按白银／黄金／棱彩区分边框。
- 支持最高输出、治疗、承伤、单杀与多杀等表现标签；展开／收起使用图标。

### 搜索召唤师、好友和最近访问

- 支持名字、完整 `名字#编号`、PUUID，以及国服互通大区账号搜索和合区参照。
- 搜索结果以小卡片显示，头像右下角显示等级；好友、最近访问在名字右侧显示 `lv.xxx`。
- 最近访问保留 20 位，好友与最近访问可独立筛选；支持进入玩家战绩和返回上一位。
- 在线、队列中、游戏中和离开状态有对应标记；等级缺失显示“—”，不增加无关的逐人查询。
- 搜索窗口标题为“搜索召唤师 (｡･ω･｡)ﾉ”，省去重复品牌标题。

### 原生入口、身份与段位

- 工具页、BP 队友头像、生涯页、好友右键、历史战报计分板和结算页打开同一套详细战绩。
- 好友右键入口复用原菜单和左侧图标，兼容两套原生好友菜单实现。
- Sona 主菜单可开关生涯详细战绩按钮，即时生效并保存；好友和其他入口独立保留。
- 编辑身份时隐藏冲突入口，官方战报中的入口避开原生回放按钮；离开选人或重建页面时清理旧按钮。
- 段位卡显示单双排、灵活组排和赛季最高，点击查看客户端返回的历史段位；未定级使用客户端完整空徽章。
- 队伍卡片小徽章统一可见大小；完整 ID、段位与胜点支持悬停查看。

### 敌方康特与配装推荐增强

- 征召选人时点击敌方已锁定英雄，查看**韩服 OP.GG 对位**；默认热门分路，可手动改分路与段位。
- 康特段位独立记忆，关闭重开、切换英雄与重启后恢复；与配装推荐段位分别保存。
- BP 预选英雄时，在锁定键左侧打开配装推荐，随当前预选英雄更新。
- 配装的装备、符文、召唤师技能、出装趋势及强化推荐同时显示**选取率条和文字胜率**；有效零值保留，缺少样本显示“—”。
- 修复配装面板尺寸与关闭按钮溢出，内容加载和窗口缩放后重新定位，提示框避开标题区域；选人和游戏中的窗口都沿用这些改进。

### 回放、显示设置和主题

- 每场回放使用一个圆形图标：先下载，完成后切换为播放，再次点击播放。
- 显示设置提供 **38 种玩家表现数据**，包含伤转、分均伤害／金币、单杀／多杀、减伤、死亡时间、资源、治疗、护盾与视野等，支持分组、搜索、批量选择与恢复默认。
- 数据选项分别作用于个人总览、队伍卡片和单场战报，保存原有选择；头像、身份、段位、装备、符文和回放保留固定布局。
- 支持全局客户端黑金和深色蓝灰主题，页面、弹窗、图标操作和悬浮提示同步切换。
- 滚动条可拖动范围加宽，轨道透明，悬停高亮；向下滚动后显示图标式回顶按钮，个人页可同时复位侧栏与主列表。
- 数据缺失和实际零值分开处理；请求支持超时、取消、重试、分页、并发保护及客户端备用战绩接口。

## 原版 Sona 功能继续保留

保留上游的自动接受、预选／锁定／禁用、选人分析、结算点赞与返回房间；OP.GG 推荐、符文和技能记忆、装备集、英雄 T 级和平衡提示；自定义签名、背景、旗帜、头像、好友状态和壁纸；窗口特效、界面精简、设置备份恢复、奖励领取、回放查询及中英文切换。各项按原有开关启用。

## 构建与发布

```sh
npm ci
npm run build
python scripts/package-release.py --pengu-zip /path/to/pengu-loader-v1.1.6.zip --output /path/to/release
```

应用构建结果在 `dist`。打包器校验固定官方 Loader ZIP 的 SHA256，生成完整一键安装包、仅插件包和 SHA256SUMS.txt；不会读取或打包本机已安装 Loader 的 config、datastore 或玩家数据。安装器使用 Windows PowerShell 5.1，无需 Python 或 Node.js。

验证包括生产构建、浏览器模拟回归、评分源码对照和隔离目录安装／失败恢复测试。浏览器演示使用虚构玩家与占位图标，真实客户端的部分接口受大区和版本影响。详见 [个人版使用说明](README_个人版.md)。
