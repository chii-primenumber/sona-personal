# Sona 个人战绩增强版

版本为 `1.10.0-personal.24`，基于 **原作者 WJZ-P** 的 **Sona v1.10.0** 定制，沿用原项目的 **AGPL-3.0** 许可。主要增强个人战绩、玩家搜索、队伍总览、对位与回放，并提供全局主题和显示设置。队伍卡片与 Akari 评分参考 Hanxven 的 [League Akari](https://github.com/LeagueAkari/LeagueAkari)，评分适配保留其 MIT 许可。[Sona 上游项目](https://github.com/WJZ-P/sona/tree/v1.10.0)

本个人版新增功能主要参考开源项目 [League Akari](https://github.com/LeagueAkari/LeagueAkari) 的个人战绩、队伍卡片、玩家搜索、数据展示与交互，并适配其评分机制。[完整功能介绍](README.md)

## 一键安装

Release 中带 `one-click-windows.zip` 的包包含官方 Pengu Loader v1.1.6、Sona、脚本与说明。完整解压后退出客户端和 Loader 管理窗口，双击「一键安装.cmd」并允许管理员授权。脚本自动寻找客户端、备份旧安装、保留自定义资源与设置、安装并激活；搜索不到时按提示粘贴目录。运行库缺失时从微软官网下载补齐。完成后重新启动客户端，按 F1 打开。

[详细安装说明、备份位置与回退方式](installer/INSTALL.md)。下列方法用于已有 Loader 时手动安装仅插件包。

## 安装与回退

1. 退出英雄联盟客户端。在 **Pengu Loader → Plugins** 中打开插件目录。
2. 将已经安装的 `sona` 文件夹整个备份到**插件目录外**。先留好这一份，以便回退。
3. 将交付目录里的 `sona` 文件夹复制到插件目录。确认结构为 `plugins/sona/index.js`，旁边有 `index.css` 和 `assets`。
4. 如果原版 `assets` 中有你自己的壁纸、视频或头像，把这些自定义文件复制到新版 `sona/assets` 中。请只启用一份 Sona。保留 `sona` 文件夹名，以便沿用原先的资源路径和设置。
5. 刷新 Pengu Loader 的插件列表，确认 Sona 已启用，再启动 LOL 客户端。个人版在客户端中显示版本 `1.10.0-personal.24`。

回退时，退出客户端，把个人版移出插件目录，再把备份的原版 `sona` 移回去，刷新插件列表后重启。定制版不会在启动时主动弹出上游更新提示，避免将定制代码误覆盖。

## 战绩入口

| 场景 | 从哪里打开 | 可以看什么 |
|---|---|---|
| 个人战绩 | **F1 → 工具 → 查询战绩**，输入 `名字#Tag`；或在开启 **英雄选择阶段增强** 后点击 BP 队友头像 | 当前段位、等级、有效样本、KDA、参团、伤害与经济占比、英雄点数、常玩英雄、近期队友及对手；每局可展开参赛者详细战报 |
| 生涯 | 点击生涯页右侧的 **详细战绩**。自己的生涯页入口位于原搜索框下方 | 打开前台生涯页对应的召唤师战绩 |
| 历史战报和结算页 | 右键计分板里的召唤师，再选择 **详细战绩** | 打开该召唤师的个人战绩 |
| 好友列表 | 右键好友，再选择 **详细战绩** | 打开该好友的个人战绩 |
| BP 预选配装 | 开启 **工具 → 配装推荐面板**，预选英雄后点击锁定键左侧的 **配装推荐** | 查看当前预选英雄的装备和符文推荐 |
| BP 己方五人 | 选人界面点击 **对局信息**。入口可在工具页的 **五人 / 十人战绩总览** 中开关 | 横排玩家卡显示段位、KDA、胜率、常玩英雄和近期对局 |
| BP 敌方英雄对位 | 排位或自定义征召选人时左键点击右侧已锁定的英雄头像 | 选择该英雄的分路和段位，查看韩服单双排的对位胜率及样本场次 |
| 开局后双方十人 | 进入游戏后切回客户端，点击与配装推荐同风格的 **对局详情**，入口替换原来的游戏进行中提示。原有的 **全局战力分析弹窗** 可在进游戏后自动打开 | 蓝红双方各一组横排玩家卡，窄窗口下自动换行 |

在详细战绩页点击「搜索玩家」，可按名字、完整的 `名字#编号` 或 PUUID 查询。左侧是可分别筛选的好友和最近访问，点击玩家打开战绩，用「返回」切回上一位。国服可选择互通大区，并通过「合区参照」查看原区服归属。最近访问在本机保留 20 位。

搜索窗口标题为「搜索召唤师 (｡･ω･｡)ﾉ」，结果以小卡片排列，等级显示在头像右下角；好友和最近访问的等级显示在名字右侧。优先使用好友在线资料和已有召唤师资料中的等级，缺失时显示「—」。

点队伍卡片的头像或名字可打开个人战绩，点卡片里的近期对局可打开单场战报。个人战绩默认每批 50 场，可改为 20 或 100 场。队伍总览支持按模式筛选。

主菜单底部的「生涯入口：开／关」可控制生涯页面的详细战绩按钮，即时生效并记住选择；好友、历史战报和结算入口独立保留。

点击「近期常玩英雄」的头像可筛选该英雄，再点一次同一头像可回到全部英雄。「最高输出」表示该玩家在这场对局中对英雄造成的伤害位列本队第一。

个人页与对局详情的常用英雄悬浮提示使用表格，包含该英雄的当前机制评分、胜负、KDA、伤转、参团和伤害／承伤／经济占比等。对局详情也可点击常用英雄筛选这张卡片，再次点击恢复全部；队伍平均数据保持完整查询范围。

战绩页的滚动条拖动区域加宽为 14 像素，轨道保持透明，悬停时提亮。滚动到下方后，右下角出现图标式回顶按钮；个人页会同时回到侧栏与战绩列表顶部。

滚动条命中区域使用独立指针反馈，鼠标移入时显示主题色高亮与细微描边，离开后恢复。

队伍卡片将单双排和灵活组排徽章与胜点并排显示，悬停可查看队列和完整段位。锁定英雄后，大头像切换为本局英雄；常玩英雄头像不再叠加场次数字，场次保留在悬浮提示中。近期对局使用蓝底表示胜利、暗红底表示失败，并配对应颜色的边框。队伍页顶部简化为一行「对局详情」，模式与场次下拉框缩小，刷新和显示设置使用图标按钮，悬停可查看操作名称。打开时直接选中当前对局的实际模式，也可手动切换其他模式。

个人战绩右上角显示当前段位徽章和各队列的赛季最高段位，未定级使用客户端的空段位徽章。队伍卡片的小段位图标统一可见尺寸，保持原始比例。单场战报的伤害、承伤与经济条以本场同项最高值为满格，旁边的百分比是队内占比。伤害条分色显示物理、魔法和真实伤害。

点击个人战绩的段位卡可查看该队列的历史段位，包含客户端提供的上赛季最高和结算。名字旁的复制按钮复制完整的 `名字#编号`。对局卡片右侧的阵容默认只显示名字，悬停可看完整 ID。选人阶段会为同一开黑队伍的名字和卡片边框使用同一种鲜明颜色，编号保留暗色。组队依据排队前的房间成员。

对局卡片的「下载回放」在客户端确认下载完成后会变为「播放回放」。可用范围取决于登录大区、客户端版本和回放状态。

个人页的刷新、显示设置和搜索使用图标按钮，悬停显示操作名称。回放使用圆形下载／播放图标，下载完成后再次点击才播放。召唤师等级显示在左上头像右下角，个人资料区不再显示已加载场次。

各页面头像右下角的等级使用半透明背景，文字保留清晰度。

英雄康特的段位筛选独立保存，关闭重开、切换英雄和重启客户端后沿用；与配装推荐段位分别记忆。配装推荐窗口适配窄窗口并保留关闭按钮位置，装备、符文、召唤师技能、出装趋势和强化推荐同时展示选取率条与文字胜率。无有效样本时显示「—」。

个人页名字完整显示在一行，窗口较窄时段位卡移到下一行，为名字与复制按钮保留空间。

主菜单左下角新增「评分：Akari／Sona」按钮，点击切换全局评分机制，并保存在本机。新配置默认使用 Akari 1.5.1 的原始 0–17 分，显示两位小数；Sona 保留 3–16 分及一位小数。已打开的个人页、队伍卡片和大厅评分立即重算，之后的选人分析也使用当前机制，无须重新查询战绩。评分口径与来源见 `AKARI评分说明.md`，原始 MIT 许可位于 `assets/licenses/LeagueAkari-MIT.txt`。

显示设置新增 38 种玩家表现数据，按输出与经济、击杀与生存、补刀与地图资源、治疗控制与视野分组，支持搜索与批量勾选。队伍卡片默认显示伤转，其余数据按需勾选；个人总览与战报也能添加相应数据。原有显示开关和已保存选择继续沿用。伤转为对英雄伤害除以获得金币，近期值取有效对局的逐场平均；缺失数据显示「—」，实际零值保留。

英雄、符文、技能、装备与海克斯的悬浮说明跟随当前主题。点击符文图标可查看本局该玩家的完整符文和效果数据。点击右上角的「显示设置」，可分别勾选五人／双方总览、个人详细战绩和单场详细战报要显示的项目。勾选会立即生效并保存在本机，每页都可以恢复默认。

在「F1 → 设置 → 插件主题」中可切换「客户端（黑金）」和「深色蓝灰」。主题会同步应用到 Sona 主面板、搜索、战绩、对位和设置弹窗，并记住选择。

「工具 → 社交 → 解锁隐藏生涯」默认开启，切换后重启客户端生效。此项作用于客户端的查看开关，页面仍取决于服务器返回的资料。

## 数据口径

- 近期统计、常玩英雄、队友与对手都来自当前已加载的样本；胜率排除重开、终止及未知胜负的对局。页面会显示有效场次。英雄点数来自独立的熟练度接口。
- 段位卡片显示查询时的段位。赛季最高段位未返回时显示「—」。部分大区的英雄点数、海克斯名称或辅助数据可能缺失。
- 客户端缺少海克斯效果说明时，海克斯大乱斗和斗魂竞技场分别从 ARAM.GG 和 CommunityDragon 读取当前公开资料，旧对局的说明可能与当时版本有差异。
- 使用客户端备用战绩接口时，按模式筛选只在最近 100 场中检索，页面会说明这个范围。新增页面不需要 ChatGPT API Key。

## 验证与源码

浏览器模拟覆盖了主题切换、玩家搜索、跨大区请求路由、显示设置、段位徽章、占比条、装备与海克斯提示，以及两个队伍页、生涯按钮和右键菜单。真实客户端的跨区接口仍待安装后确认。

定制源码和修改记录保存在本地 Git 分支 `personal/match-history`。安装依赖后运行 `npm run build`，构建结果保存在 `dist`。
