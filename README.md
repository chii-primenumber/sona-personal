# Sona 个人战绩增强版

基于 **原作者 WJZ-P** 的开源项目 **Sona v1.10.0** 定制，通过 Pengu Loader 加载，沿用原项目的 **AGPL-3.0** 许可。[原项目](https://github.com/WJZ-P/sona)

本版围绕战绩查询和对局信息做了以下增强。

- **个人战绩与单场战报**整合玩家总览、英雄统计、近期队友与对手、段位详情和十人数据，补充伤害占比条及装备、海克斯悬浮说明。
- **对局信息与查询入口**提供 BP 己方五人和开局后双方十人总览、预组队同色标记，并接入队友头像、生涯页和计分板右键菜单。
- **玩家搜索、对位和回放**支持好友、最近访问及国服互通大区搜索，点击已锁定的敌方英雄查看韩服 OP.GG 对位，可直接从记录下载并播放回放。
- **界面与显示设置**统一客户端黑金和深色蓝灰主题、透明底滚动条、玩家 ID 显示和复制，并可勾选各战绩页面显示的数据。

队伍卡片布局参考 League Akari。本次定制整理于 2026-11-07。[个人版安装与回退说明](README_个人版.md) · [完整更新记录](CHANGELOG.md)

## 安装

从 [本仓库 Releases](https://github.com/chii-primenumber/sona-personal/releases) 下载安装 ZIP，解压后将其中的 sona 文件夹放入 Pengu Loader 的插件目录。替换前备份旧版及自定义资源，重启客户端后按 **F1** 打开。
